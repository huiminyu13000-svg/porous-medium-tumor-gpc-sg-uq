# Attribution

This package reorganizes the research code supplied for Jiang, Liu, and Yu's tumor-growth UQ study. The front-capturing solver source retains the attribution to Xu'an Dou (2020). The `lgwt.m` source retains its original Greg von Winckel attribution. The experiment entry point, explicit configuration, input generation, and plotting organization have been prepared for the accompanying defense material. Original author notices are preserved in the source files.
